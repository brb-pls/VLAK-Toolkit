Drop a period-correct IBM VGA style .ttf/.otf here and the launcher will pick
it up automatically at startup (no system install needed on Windows).

Recommended free font: "Perfect DOS VGA 437" from int10h.org's
"Ultimate Oldschool PC Font Pack" (https://int10h.org/oldschool-pc-fonts/).
Just download it, grab the .ttf file, and drop it in this folder.

If this folder is empty, the launcher falls back to a plain monospace font
(Consolas/Courier New) so it still looks reasonably retro either way.
